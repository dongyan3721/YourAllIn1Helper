# All-in-One Toolbox 0.1.5.beta

Windows x64 测试版，修复两项 beta 反馈。

- 多显示器截图现在默认覆盖扩展桌面。支持在副屏截图、跨屏拖选，以及将跨屏选区导出为一张图片。
- 置顶标记按角标窗口大小居中缩放。图钉与悬停时的取消置顶图标均适配圆形标记。

## 安装与升级

下载 `All-in-One-Toolbox_0.1.5-beta_windows_x64.msi`。首次安装可直接运行安装器。已安装的用户可以正常退出应用后运行 MSI 覆盖升级，也可以由应用在后台下载并校验签名，正常退出时安装更新。每用户安装范围和应用数据目录沿用 Windows 旧版的配置。

## 验证

Windows 桌面端编译检查、截图与平台测试、前端测试和生产构建通过。模拟双屏回归覆盖不同缩放比例、负坐标和跨屏导出像素。本次机器只有一块显示器，真实双屏与混合 DPI 的界面表现待复测。
