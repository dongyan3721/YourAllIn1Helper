# All-in-One Toolbox 0.1.3.beta

Windows x64 beta 版本，密码本新增类似 Google Authenticator 的一次性验证码。

## 新增

- 密码本条目的「TOTP 密钥」支持 Base32 密钥和 `otpauth://totp`、`otpauth://hotp` 链接，覆盖时间型（TOTP）与计数器型（HOTP），支持 SHA-1/256/512、6–8 位验证码和自定义周期。
- 打开条目即可看到当前验证码：时间型带倒计时并自动换新，最后 5 秒变红；计数器型点「下一个」才推进计数，新的计数会随条目加密保存，重复点击不会跳号。
- 验证码在后端解密密钥后计算，密钥不会因此额外发送到界面；列表里用盾牌图标标记已配置验证码的条目。
- 「复制验证码」使用与复制密码相同的安全剪贴板，30 秒后仅清除仍未被改动的内容。
- 密钥无效时只在验证码卡片内提示，不会锁定密码本。

## 安装与升级

下载 `All-in-One-Toolbox_0.1.3-beta_windows_x64.msi`。新用户直接安装；已有版本也可正常退出软件后运行 MSI 覆盖升级。安装范围、应用标识和数据目录保持不变，保留原有设置、历史记录、便笺和密码本，已保存的条目无需迁移。

已安装 0.1.1-beta 的用户可通过应用后台自动更新升级：启动后约 15 秒首次检查，此后每 6 小时检查；后台下载并校验签名后，在用户正常“退出”时静默安装，下次打开生效。关闭主窗口可能仅隐藏到托盘。

## 验证

- 验证码算法通过 RFC 4226（HOTP）与 RFC 6238（TOTP，SHA-1/256/512）官方测试向量。
- 密码本服务、IPC 锁定、前端面板自动化测试通过。
- 尚未用真实服务商的密钥做人工对码验收；云端备份与导入导出暂未提供。

本版继续使用每用户 Windows x64 MSI 及独立 updater 签名，未配置 Authenticode 发布者证书。下载附件中的 `SHA256SUMS.txt` 可用于校验文件。媒体处理仍需自行安装 FFmpeg/FFprobe。
