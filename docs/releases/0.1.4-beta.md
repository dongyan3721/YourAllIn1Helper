# v0.1.4-beta — macOS Apple Silicon

本次是 macOS beta，适用于 Apple Silicon（arm64 / aarch64）。Windows 请继续使用已验证的 v0.1.3-beta；本次不提供新的 Windows 安装包，也不变更其更新通道。

- 加入 macOS 签名更新支持：仅 /Applications 或当前用户 ~/Applications 内的正式同名安装包检查更新；调试、QA、dist 与挂载 DMG 内运行不参与更新。
- 更新包验证签名后暂存，正常退出并完成模块收尾后安装；关闭红色按钮仍为后台运行，不触发安装。
- GIF 录制的排除窗口失效时停止录制，避免将本应排除的内容录入。
- 修复 macOS 翻译浮窗超出屏幕工作区边界。
- 包含 Windows 阶段引入的新版界面和 OTP 功能；本次 macOS 验证范围见仓库测试记录。

下载 `.dmg`，打开后将 App 拖入 Applications。DMG、签名更新压缩包及 SHA-256 校验清单随本 Release 提供。首次发布 macOS 通道使用独立的更新签名公钥，不影响 Windows 已发布公钥。

当前 App 使用本机固定自签名开发证书，**没有 Apple Developer ID 签名，也没有 Apple 公证**。因此这不是可在任意 Mac 上直接获得 Gatekeeper 信任的正式分发包；macOS 可能阻止打开。更新包签名验证与 Apple 的分发信任是两回事。Intel Mac 未构建和验证，不在本次支持范围内。

协作：Codex 统筹集成与验证；原功能分支由 Qoder 实现。后续协作统一使用用户在 Zed 配置的 ACP Agent，沿用用户所选模型。
