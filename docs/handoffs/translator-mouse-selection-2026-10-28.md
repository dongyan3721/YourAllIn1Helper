# 全局翻译：鼠标划词入口

实施：OpenAI Codex，2026-10-28。基线为生物识别未完成检查点 `2cece49`；本轮未继续证书/Touch ID 联调。

## 本轮行为

- 在翻译设置中增加「鼠标划词翻译」，默认关闭，非敏感配置随模块设置持久化。
- macOS 全局鼠标监视只识别第三方应用内超过 6 点的左键拖选，不拦截事件。串行后台线程等待 mouseUp 处理，再以 AX 原生接口读取选区。读前、读后核对前台 PID 与手势代次，丢弃过时结果。
- 有文本时显示不抢焦点的 20×20「译」按钮。此时不调用翻译服务；点击后才把缓存选区交给既有翻译浮窗，沿用 Google/DeepL/OpenAI 兼容服务和 Keychain 凭据。
- 新的外部点击、八秒无操作、关闭选项、停用模块都会清理入口。选区一次消费，窗口创建失败清理缓存；停用后不能恢复旧选区。
- 浮窗接入配置中的宽高并限制在所在显示器范围内；AX 请求设置一秒消息超时。
- 自动划词取词遇到无权限/不支持时不循环弹窗；原有全局快捷键保留错误引导和手动输入入口。应用退出移除原生监视器。

## 验证

- `cargo test -p mod-translator -p all-in-one-host --lib --tests --offline`：全部通过（翻译模块 10 单元、7 HTTP/TLS/SSE fixture、4 生命周期；宿主 20 单元及 21 集成）。
- `cargo test -p all-in-one-host --lib translator_mouse --offline`：新增手势过滤测试通过。
- `pnpm --dir src-ui test` 与 `pnpm --dir src-ui run build`：72 项通过，严格类型检查与生产打包通过；包含实际入口组件的脚本执行测试，验证未点击不调用 IPC、重复点击只提交一次。
- 此处没有真实第三方翻译 API 调用，没有读取用户密钥，没有执行新包的真实跨应用 GUI 验收。
