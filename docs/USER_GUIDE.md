# All-in-One Toolbox 使用说明

## 从这里开始

主窗口只有两个页面：**功能**与**偏好设置**。在“功能”页打开或关闭某项功能，点击该项下方的“打开面板”，在独立窗口中操作或调整设置。重复打开会前置已有面板；关闭面板不等于停用功能，全局快捷键仍然可用。

关闭主窗口后，软件可继续在托盘运行。要结束进程，请点主窗口的“退出”或托盘菜单中的退出。

“使用说明”打开的就是本地 Markdown 文件，无需联网。每个功能面板也有这个入口。软件随包携带说明，发布版本会把说明放到应用数据目录的 docs 子目录，之后交给系统的默认编辑器打开；Windows 未关联 Markdown 时使用记事本。

## 偏好设置

Windows MSI 安装版会在后台检查、下载并校验新版本，在通过“退出”正常结束软件后静默安装，下次打开即使用新版本。升级保留原有设置和数据。开发版和便携 EXE 不自动升级。

- **界面语言**：简体中文、English、日本語。
- **外观**：跟随系统、浅色、深色；可选择强调色。
- **快捷键**：展开对应功能，点击快捷键框，按下新的组合键，再点“保存”。Escape 放弃本次录入，Tab 移到下一个控件。“默认”恢复该动作的初始组合键。
- **检测冲突**：在偏好设置中点击“检测冲突”，检查已设置的全局组合键；录入新的组合键后也会自动检查。内部重复会显示具体功能和动作，系统无法注册时会提示可能被其他程序占用或系统保留。
- 检测不修改配置或接管其他程序的快捷键。可用性是当前时刻的注册结果，不能列出其他应用内部的局部快捷键；保存时仍会再次校验并注册。
- 保存快捷键时会校验格式、功能之间的冲突和系统注册结果。失败时保留原来的设置。功能关闭时仍可修改它的快捷键，重新开启后生效。
- 每个功能都有“打开面板”快捷键，除密码本默认 Ctrl+Alt+E 外，初始为未设置。保存组合键即可从其他应用呼出该面板；“清除”撤销这项绑定。
- 单个脚本的快捷键在“脚本”面板中管理。

下表列出 Windows 默认快捷键。修改后以偏好设置中显示的值为准。macOS 上 Ctrl 对应主要修饰键 Command，Alt 对应 Option。

| 功能 | 默认快捷键 |
| --- | --- |
| 截图 | Ctrl+Alt+A |
| 长截图、GIF、OCR | 未设置 |
| 剪贴板候选窗口 | Ctrl+Alt+D |
| 屏幕注释开始/结束 | Ctrl+Alt+Shift+B |
| 屏幕注释鼠标穿透 | Ctrl+Alt+Shift+S |
| 新建便笺 | 未设置 |
| 翻译外部应用选区 | Ctrl+Alt+Shift+T |
| 置顶/取消置顶当前窗口 | Ctrl+Alt+Shift+C |
| 准星选择置顶窗口 | Ctrl+Alt+Shift+W |
| 密码本面板 | Ctrl+Alt+E |
| 其他功能面板 | 未设置 |

## 截图、长截图、GIF 与贴图

按 Ctrl+Alt+A 或在截图面板中开始截图，框选区域。可调整选区，使用矩形、箭头、文字、马赛克等标注工具；撤销与重做只作用于当前编辑。

- **保存**：选择“另存为”可打开系统路径选择框；“保存在默认路径”直接写入截图设置里的默认目录。保存成功后会短暂提示文件路径。面板可设置目录、文件名前缀和默认标注样式。
- **复制**：把当前图像放入剪贴板，再到目标应用粘贴。
- **贴图**：把图像作为浮动窗口放在桌面；滚轮缩放，可调整透明度、复制、保存或关闭。截图面板可管理所有贴图。
- **长截图**：在面板中启动长截图，选择滚动内容区域后向下滚动，查看拼接预览并结束。选择连续、稳定的内容区域，避开固定工具栏、动画和反复变化的区域。
- **GIF**：框选后点击 GIF 并开始录制，完成后停止并导出。录制时保持目标内容可见。录制中再次按“截图”或“GIF”快捷键，或点击托盘的“截图”，会结束录制并显示预览；全屏选区没有区域外的控制条时也可用此方式停止。快捷键以偏好设置中的实际配置为准。
- **OCR**：在面板中点击“截图识字”并框选文字。Windows 使用本机可用的系统 OCR，识别语言受系统语言资源影响。识别结果不会由应用伪造。
- Escape 可取消当前抓取。部分受保护的视频画面可能不允许系统抓取。

## 剪贴板

开启功能后，复制的文本和图像会进入本地历史，按 Ctrl+Alt+D 打开候选窗口。使用上下键选择，Enter 粘贴；也可点击候选条目的粘贴按钮。Escape 关闭。

管理面板可搜索、固定、删除条目，或清理未固定内容。固定内容用于保留常用条目。粘贴操作依赖目标应用接受窗口激活与模拟按键；某些编辑器自身的快捷键可能与全局快捷键冲突，可在偏好设置中更换。

## 屏幕注释

按 Ctrl+Alt+Shift+B 或在面板中开始，出现透明画布和独立工具栏。工具栏提供笔、形状、文字、橡皮擦、颜色与粗细等操作；激光笔轨迹会自动消退。

按 Ctrl+Alt+Shift+S 切换鼠标穿透：穿透时可以操作下面的应用，切回后继续绘制。面板可清空墨迹或结束会话。再次按 Ctrl+Alt+Shift+B 结束注释。

## 便笺

在便笺面板中新建。每张便笺有独立窗口，支持 Markdown、公式、主题和透明度。内容自动保存；请关注保存失败的提示。

便笺库可重新打开、关闭、导出 Markdown 或删除便笺。关闭窗口保留内容，删除才会移除记录。导出使用系统保存对话框，保存成功后短暂提示完整路径。

## 应用使用时长

打开面板查看按日期、应用聚合的使用记录，可选择日期范围和查看图表。统计依赖系统前台应用、空闲与会话状态，锁屏和空闲行为按当前统计设置处理。

记录保存在本机。停用功能会停止采集，已有记录保留。

## 脚本

创建脚本，选择类型和内联内容或本地文件，设置参数、工作目录、超时与输出方式。可为单个脚本设置快捷键或加入托盘菜单。

解释器使用本机已有的安装。若提示未找到 Python、Node、PowerShell 等，请确认相应解释器已安装并能被 PATH 或配置路径找到。

运行后在面板查看状态、标准输出与错误输出。长时间任务可取消，超时任务会被终止。脚本以当前用户权限运行，参数与工作目录会影响它的行为。

## 翻译与自定义 LLM

在翻译面板选择服务提供商，配置它需要的 API Key。使用自定义 OpenAI 兼容服务时，添加唯一 ID、名称、端点和模型名称，再选择该服务、保存密钥。

端点可以填写服务根地址、包含 `/v1` 的 base URL，或完整的 `/chat/completions` 地址。请使用服务商给出的模型名；软件不会把请求转到其他服务或生成模拟结果。

输入原文，选择目标语言后翻译。也可在其他应用选中文字，按 Ctrl+Alt+Shift+T，在浮窗中查看译文。鼠标划词入口需要在翻译面板中启用；部分应用不会向系统提供选区，届时可手动输入。

密钥在正常桌面模式保存到本应用的系统凭据条目；测试/系统凭据不可用时，界面会明确标注为仅本次会话保存。未配置、认证失败或网络错误会显示实际错误。翻译自动复制和本地历史暂未实现，界面中的对应选项不可用。

## 媒体处理

选择文件，设置输出目录与并发数，再选择图片或音视频处理。也可把支持的文件拖入面板。

- 图片：选择格式，按需填写尺寸、保持宽高比与质量。
- 视频/音频：可转换格式、裁剪时间范围、提取音频、调整音量。时间单位为秒，结束必须晚于开始。
- 快速裁剪采用流复制，起点精度受关键帧影响；精准裁剪会重新编码。
- 音量 1 表示原音量，0.25 表示四分之一幅度，超过 1 表示放大。
- 任务提交后查看队列进度，可取消正在等待或处理的任务。原文件不会覆盖，输出重名时追加序号。

图片处理使用内置 Rust 编解码。音视频处理需要本机 FFmpeg 和 FFprobe；环境区显示实际检测结果，软件不会自动安装它们。

## 窗口置顶

把目标窗口放到前台，按 Ctrl+Alt+Shift+C 切换置顶。也可打开面板搜索窗口，在对应行选择置顶、取消置顶或激活。Ctrl+Alt+Shift+W 启动准星拾取。

“一键还原”取消本软件管理的全部外部窗口置顶；退出软件也会尝试还原。系统权限高于本软件的窗口可能不能被控制；当前系统不支持时，界面会提示。

## 密码本

首次使用设置主密码，之后通过主密码解锁。面板支持条目、搜索、密码生成和一次性验证码（TOTP / HOTP）。关闭密码本面板会锁定；再次打开需重新解锁。

### 一次性验证码（类似 Google Authenticator）

在条目的「TOTP 密钥」里填写以下任一内容并保存：

- 服务商给出的 Base32 密钥（可含空格或连字符，不区分大小写），按默认的 6 位、30 秒、SHA-1 处理。
- `otpauth://totp/...` 链接：支持 `algorithm`（SHA1/SHA256/SHA512）、`digits`（6–8）、`period`。
- `otpauth://hotp/...` 链接：计数器型，使用 `counter` 参数作为当前计数。

之后打开该条目，编辑区顶部会显示当前验证码：

- 时间型验证码带倒计时，最后 5 秒变红，过期后自动换新。
- 计数器型验证码只在点「下一个」时推进计数；新的计数会和条目一起加密保存。
- 「复制验证码」走与复制密码相同的安全剪贴板，30 秒后清除。

验证码在后端计算，密钥本身不会因此额外发送到界面。修改了 TOTP 密钥但还没保存时，验证码卡片会暂时隐藏。

Windows Hello 或 macOS Touch ID 需要先使用主密码解锁，再在密码本面板中登记。认证由系统界面完成，取消不会解锁。主密码始终可以使用。

复制密码后，软件只在剪贴板仍是本次写入内容时执行到期清除，避免清除你后来复制的其他内容。请按界面提示保管主密码和数据备份。
