## 修改范围

- 功能页、屏幕注释工具条和托盘的全局快捷键说明读取实际配置；未分配时不显示虚构组合键。Windows 使用 Ctrl/Alt，macOS 使用 Command/Option。截图内部复制、保存等局部操作的提示只显示当前平台修饰键。
- 全局默认键统一为 PrimaryMod + SecondaryMod 系列：截图 A、剪贴板 D、密码本面板 E；屏幕注释 Shift+B、穿透 Shift+S、翻译 Shift+T、置顶当前 Shift+C、准星 Shift+W。GIF、长截图、OCR、新建便笺及其他面板默认未分配，按钮和托盘仍可执行。
- 保留用户 shortcut_overrides。配置版本 3 → 4 只迁移旧的翻译内置默认值，保留自定义翻译热键和未知字段。
- Windows 窗口列表读取真实 WS_EX_TOPMOST，并结合本工具管理列表显示置顶状态。启用 Windows 图钉角标守护；角标为 28 个逻辑像素、支持物理坐标及缩放，避开标题栏按钮，不获取键盘焦点。最小化时隐藏角标，关闭后清理记录；串行化置顶、取消及后台维护，防止旧快照重新置顶。
- 翻译主界面、API 密钥、选择框和自定义服务表单采用全局明暗主题变量；原生表单控件使用相应 color-scheme。
- 便笺导出使用系统 Markdown 保存对话框，先冲刷最新内容；取消不写文件，保存后显示完整路径。
- “保存默认”改为“保存在默认路径”。截图、贴图、长截图、GIF、屏幕注释、媒体输出共用原生短暂路径通知，设置、脚本和密码本条目保存提供页内提示。自动保存便笺不逐次弹出提示。
- 截图导出在工作线程发出保存通知，避免遮罩销毁使原异步 IPC 回调被取消；通知窗口不依赖原窗口存活，不抢焦点，自动关闭。
