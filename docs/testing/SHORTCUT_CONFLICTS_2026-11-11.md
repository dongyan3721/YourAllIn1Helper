# 快捷键冲突检测（Windows，2026-11-11）

偏好设置新增“检测冲突”：检查全部已设置的组合键，跳过未设置的可选面板绑定，并在功能分组上标记需要调整的数量。录制新组合键后自动预检，保存之前再次检查。

检测结果区分：当前可用、内部重复、系统无法注册、格式不支持、检测失败、未检测系统占用。内部重复显示具体功能和动作，包含关闭功能保留的默认/自定义绑定及动态脚本绑定。关闭功能在冲突对象名称中有标记。冲突或检测失败时禁止保存该草稿；用户可改键、恢复默认或清除可选绑定。

原生检测使用实际全局快捷键注册 API。已由本程序持有的组合键不注销、不替换回调；未持有的组合键进行无回调的短暂注册，并立即释放。失败的注册不注销其他注册者的绑定；释放失败会报告检测失败，不能误报可用。原生检测、全部重新注册和脚本绑定变更共用互斥保护。

检测不写配置、运行时逻辑注册表或脚本，不触发功能。检测结果只代表当前注册可用性，保存仍走现有校验与失败回滚。系统注册失败可能是其他程序占用、系统保留或平台限制，不据此猜测占用程序名称；不扫描其他应用内部的局部快捷键。

前端对自动检查和批量检查设置结果版本，迟到结果不会覆盖新录入的组合键。批量扫描包含尚未保存的草稿；用户在扫描中修改输入时丢弃旧扫描结果。
