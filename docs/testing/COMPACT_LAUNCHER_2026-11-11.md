# 两页式主窗口与独立功能面板（2026-11-11）

## 界面调整

主窗口默认 760×640，仅保留“功能”和“偏好设置”两个入口。“功能”页以两列紧凑条目显示十项功能，每项包含开关与独立的打开链接。移除主窗口的原生窗口数、运行指标、环境探测表和十项功能横向导航。

功能窗口按 `feature-{module_id}` 按需创建，默认 1000×730。重复打开复用同一窗口，关闭面板保留模块运行与快捷键；停用模块销毁其功能窗口。媒体文件选择框使用调用方窗口作为 owner，截图开始时同时隐藏主窗口与截图功能面板，密码本功能窗口关闭时锁定。

偏好页集中语言、浅色/深色/跟随系统、强调色与快捷键，快捷键按功能折叠。现有功能动作可改键或恢复默认；每项功能另外提供一个默认未设置的“打开面板”绑定，支持设置与清除。脚本自身的执行快捷键仍由脚本面板管理。

旧的 `/media`、`/translator`、`/vault` 等入口继续可用，但打开独立功能窗口。各面板保留原来的操作与专属设置。较长的截图和屏幕注释操作指南移入唯一用户手册 `docs/USER_GUIDE.md`；主窗口和功能面板的“使用说明”把内嵌手册写入应用数据目录的固定文件，再交给系统编辑器打开。Windows 未关联 Markdown 时回退记事本。

前端入口采用异步组件与分包加载。重构前主 JS 约 685.70 KB，重构后约 202.26 KB；这是初始入口的缩小，并非所有功能总资源减少。未打开的功能不提前挂载；独立面板也只轮询自己的列表，主窗口不再轮询全部剪贴板、便笺和外部窗口记录。

## 快捷键行为

配置更新检查格式、模块间冲突、关闭功能预留的绑定和动态脚本绑定。持久化失败不更改运行时，原生注册失败则回滚旧配置和旧绑定。关闭的功能可以先设置绑定，重新启用时恢复注册。

Windows 会截走已注册组合键，普通 DOM 键盘事件收不到。录制字段聚焦时，本软件把自己的已注册组合键转发给同一个录制窗口，阻止执行原动作；普通新组合键仍由 DOM 录入。失焦、页面卸载、窗口关闭或退出清理录制状态，动态脚本绑定也遵守该机制。
