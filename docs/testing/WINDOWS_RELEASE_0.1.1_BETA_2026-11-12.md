# 0.1.1-beta Windows 发布验证

本版包含 `f738111` 的 GIF 修复。应用 SemVer 为 `0.1.1-beta`，MSI ProductVersion 为 `0.1.1`。

- 前端 TypeScript 检查通过，97 项前端测试通过。
- 最终优化版内嵌前端经过真实 WebView2 动画录制：区域录制 30 帧（红 15、蓝 14，首帧为过渡画面），全屏录制 26 帧（红 13、蓝 13）；截图动作结束录制并保留当前会话，解码结果包含真实动态像素。
- 核对 EXE 内嵌最终 `CaptureOverlay` 资源，与本次前端构建一致。
- MSI 的 updater 签名、公钥、签名中的应用版本均验证通过，修改安装包一个字节后验证拒绝。
- 与已发布 `0.1.0-beta` MSI 对比：UpgradeCode、公钥、每用户安装范围和删除目录范围不变；ProductCode 更新，升级表接受旧版，替换旧产品的动作位于安装事务内。
- 当前机器已有用户确认可用的安装版，本轮没有卸载或覆盖该安装，也没有修改其应用数据。本次升级验证为真实 MSI 数据库和旧包的兼容性核对，并非再次执行安装。
- 网易 UU 虚拟屏的此前问题由用户确认已修复；本轮未另行建立 UU 远程会话。

发布顺序：先推送发布分支和标签，上传草稿附件并核对远端 SHA256，公开 prerelease，然后快进合并并推送 master 更新 feed。旧版不会在新附件公开前收到新版本 feed。

本机日志与 MSI 元数据结果位于 `.runtime_data/release011-*`；公开产物与 SHA256 清单位于 `dist/v0.1.1-beta`。签名私钥继续保存在仓库外，不随产物发布。
