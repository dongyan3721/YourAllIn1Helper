# 功能 10：密码本 GUI 验收用例

- 用例初版：2026-10-25；预期更新：2026-10-28
- 范围：主密码闭环、秘密复制及剪贴板租约；生物识别明确不做。
- 本文为用例清单，表中保留初始未执行状态，不作为通过报告。最新执行结果见 [2026-10-28 专项报告](VAULT_GUI_REPORT_2026-10-28.md)。
- 数据约束：只能使用本文虚构值；不得读取或导入现有密码、浏览器凭据、个人数据库，不得触发 Touch ID / Windows Hello，不得写系统钥匙串。

## 隔离准备

1. 新建一个专用空目录作为 `ALL_IN_ONE_GUI_TEST_DATA_DIR`，不得指向日常应用数据目录。
2. 从本 worktree 构建并启动真实 Tauri 应用，保持该环境变量只作用于测试进程。
3. 打开主面板 `/vault`，确认使用独立测试数据库。
4. 统一虚构数据：
   - 初始主密码：`fiction-M1-master-2026`；修改后：`fiction-M1-renewed-2026`。
   - 条目标题：`Fiction M1 Account`；用户名：`fiction-user`；URL：`https://example.invalid`。
   - 密码：`fiction-entry-password`；TOTP：`FICTION-TOTP-NOT-REAL`；备注：`fiction searchable note`。
