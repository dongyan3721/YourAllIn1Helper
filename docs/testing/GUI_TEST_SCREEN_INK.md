# 功能 03：桌面屏幕注释（Screen Ink）专属图形界面回归测试用例

## 1. 概述与测试规范

本用例文档专门针对子功能 03 **桌面屏幕注释（Screen Ink）** 进行编制。
依据任务书要求，本用例严格区分单元测试、IPC 集成测试与实际 GUI 交互验证：
- **真实系统能力**：底图截屏经由注入的 `ScreenCapturer` 获取单帧，墨迹 Alpha 合成使用 `image` 引擎，系统剪贴板写入使用 `arboard`；
- **状态标定原则**：在当前无图形桌面交互或 CI 运行环境下无法进行真实人工指针操作的 GUI 用例，**如实标为「未执行」**，严禁将 Rust IPC 或无头单元测试伪造为 GUI 已通过。
