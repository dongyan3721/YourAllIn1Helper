# macOS 图形界面回归测试计划

## 目的与执行要求

将 GUI 回归作为测试工程必备检查，与单元测试、IPC 集成测试、原生窗口烟测分开记录。交付包必须来自当前源码，测试对象为 `dist/All-in-One Toolbox.app` 中的 release 可执行文件。通过 Computer Use 实际点击、输入及按键验证，不以调用 IPC 或数据库查询代替界面断言。

使用环境变量 `ALL_IN_ONE_GUI_TEST_DATA_DIR` 指向项目 `.runtime_data/gui-qa-20261024/`，隔离数据库、配置及便笺。该模式仍使用真实系统能力。执行记录注明测试数据、预期结果、实际界面、证据及结论；未执行项不得标为通过。对正常使用的数据不执行清空或删除。

## 构建前置

1. 执行前端 TypeScript 检查和生产构建。
2. 执行 `scripts/package_macos_app.sh` 生成标准 `.app` 并复制至 `dist/`。
3. 记录 macOS、架构、源码状态、构建时间、App/可执行文件 SHA-256。
4. 在应用退出后执行 `python3 scripts/prepare_gui_test_app.py`，生成带 `LSEnvironment` 的 QA 副本及构建清单。QA 副本仅修改 Info.plist 的身份与测试目录环境变量，可执行文件和资源与交付包保持一致。
5. 用 Computer Use 打开 `.runtime_data/gui-qa/All-in-One Toolbox QA.app`。重启测试必须复用该副本和同一测试目录；不使用会自动改变模块状态的 `--ui-smoke-test` 代替人工交互回归。

完整命令：

```sh
pnpm --dir src-ui run build
bash scripts/package_macos_app.sh
python3 scripts/prepare_gui_test_app.py
```

其中 `prepare_gui_test_app.py` 只准备文件，不启动应用。普通发布 App 仍位于 `dist/All-in-One Toolbox.app`，不会自动启用 QA 数据目录。

## 发布门槛

GUI-01/02/05/06/08/09/11/12/16/18/19 是本阶段关键回归。出现崩溃、数据丢失、模块关闭后仍执行或开关无法持久化则不通过。系统不支持的能力应验证准确提示及禁用状态，不应尝试绕过系统安全限制。缺陷需记录复现步骤、严重性、修复内容及复测结果。
