# 历史粘贴目标焦点修复（2026-10-28）

## 问题与修复

用户反馈历史面板粘贴不进入原应用，反而显示主界面。原实现仅关闭面板、等待 140 ms 后发送 Cmd+V，没有保留原应用；macOS 可能将同一 App 的主窗口变为前台。

提交 328d001 在面板打开前捕获真实前台应用 PID；关闭后先等原生销毁队列，再激活已保存的原应用。只有确认该进程成为前台后才发送 Cmd+V；目标已退出或一秒内未取得焦点时取消粘贴。关闭/失焦路径不主动激活原应用，避免干扰用户切换窗口。直接从本应用打开面板时不猜测其他目标。
