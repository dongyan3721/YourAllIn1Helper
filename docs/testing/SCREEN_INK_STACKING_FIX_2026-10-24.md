# 屏幕注释工具栏遮挡修复

用户发现画布覆盖工具栏，无法切换样式或结束注释。两个同级置顶窗口不能保证相互顺序；已建立原生父子关系，并在 macOS 将工具栏设为高于画布的窗口层。隐藏恢复后重新绑定关系，退出时先销毁工具栏再销毁画布。

另外补齐主面板与注释窗口的 Tauri 事件监听/注销权限；主面板订阅内核更新，并在订阅失败时继续轮询，避免退出后仍显示旧状态。

验证记录：

- 新增原生层级回归在旧实现上失败；修复后通过，覆盖画布重新聚焦、窗口隐藏恢复后的父子关系、实际 Z 顺序与退出清理。
- 工作区 Rust 测试 76 通过、0 失败、1 忽略；前端 4 通过；严格前端构建和 App 打包通过。
- 实际 GUI 已验证工具栏切换荧光笔、矩形、箭头、颜色、线宽、穿透模式及关闭注释。截图 01–04 为首轮层级修复构建，05 为增加主面板刷新监听的后续构建；构建记录保留各阶段校验值。
- 用户随后明确反馈“功能我帮你测过了，没问题”，要求停止扩展测试并提交。
- 最后的事件权限配置随最终 App 打包成功，未再追加桌面自动化；Windows 和完整多显示器验收仍未执行。
