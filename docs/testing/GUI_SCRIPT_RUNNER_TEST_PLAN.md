# 功能 06「自定义脚本」GUI 回归用例

> 集成阶段已有部分真实 GUI 执行结果，见 [2026-10-24 集成报告](INTEGRATION_REPORT_2026-10-24.md)。下表保留并行开发阶段的原始记录，不能用局部执行结果将整项用例改为通过。

## 目的与状态

本文件只覆盖 `script_runner` 模块的主控台脚本库、解释器探测、运行日志、快捷键与托盘入口，与通用 GUI 计划
[`GUI_TEST_PLAN.md`](GUI_TEST_PLAN.md) 配合使用。

> 本次并行开发会话无法实际打开 release App 并完成鼠标、键盘、托盘和系统快捷键操作，因此下表全部标记为
> **未执行**。Rust 单元/IPC 测试与前端构建结果不能作为 GUI 通过证据，也没有被写成 GUI 通过。

执行时使用独立数据目录，禁止修改日常数据库和文件：

```sh
export ALL_IN_ONE_GUI_TEST_DATA_DIR="$PWD/.runtime_data/gui-qa-script-runner"
mkdir -p "$ALL_IN_ONE_GUI_TEST_DATA_DIR"
```

GUI 测试对象必须是当前源码构建的 release App；执行前记录 macOS 版本、架构、源码提交、
App 与可执行文件 SHA-256。每个用例保存截图或录屏到 `docs/testing/evidence/`，未实际观察到的项保持“未执行”。

## 发布门槛

GS-01/02/04/05/06/11/12/13/14/15 为关键用例。出现脚本在保存/初始化时自动执行、停用后仍执行、
快捷键或托盘配置显示已生效但实际未注册、Unsupported 能力被显示为可用、子进程残留或数据丢失时判定不通过。
