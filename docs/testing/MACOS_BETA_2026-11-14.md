## 本轮未覆盖及分发限制

- 未重跑密码本完整 CRUD / OTP GUI、锁屏/睡眠、全局粘贴目标应用、长截图拼接、真实 GIF 连续录制、屏幕注释完整绘制、多屏翻译边界。自动测试覆盖不等同于上述 GUI 已通过。
- 本次验证更新包下载与验签，未用更高版本实际替换日常安装，不宣称跨版本 TCC 继承已实测。
- 未构建或实测 Intel Mac；本轮未重新运行 Windows。
- 本机固定自签名开发证书，**没有 Apple Developer ID 和公证**；其他 Mac 的 Gatekeeper 不会自动信任。beta 产物不等同于已公证的正式分发版本。
- 自动更新只允许 `/Applications/All-in-One Toolbox.app` 和当前用户的同名 `~/Applications` 安装；排除调试、QA、构建、dist、DMG、下载目录。feed 仅包含真实签名的 darwin-aarch64。
