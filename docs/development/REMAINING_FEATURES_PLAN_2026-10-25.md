## 先行公共工作（Codex 负责）

1. **并发剪贴板保护**：现有 EventBus 只有单个 `AtomicBool`，翻译和密码本重叠使用时，一个操作解除屏蔽会提前放开另一个。新增有所有者/引用计数的 RAII 租约，异常和取消均释放；保持旧调用兼容。共享接口和宿主剪贴板服务由 Codex 统一维护。
2. **真实能力与权限**：OCR、选区读取、生物识别、空闲/锁屏检测目前仍有 Unsupported。各模块按能力注入，适配器分文件实现；缺权限/不支持/用户取消分别报告。新增窗口的事件监听权限采用最小范围，不能依赖吞掉的监听错误。
3. **隐私与凭据**：翻译 API Key、密码本 DEK 不能明文写入配置/日志；明确系统凭据库的包装/访问控制契约。后端只返回必要信息，敏感值不广播。开发、测试仅用专门构造的数据。
4. **窗口规则**：全屏层和浮动控件必须明确原生层级/owner，复用此次 `ink_window` 的经验但不直接依赖屏幕注释业务；不能只检查窗口存在。涉及隐藏恢复、聚焦、销毁顺序都要验收。
5. **统一集成口径**：保持十槽位目录和原 ID；模块可用数依据实际挂载生成。数据库迁移保留旧六模块数据。公共 API 调整先写契约与调用点清单，再实施。

以上是计划中的实现工作，尚未修改公共接口。07 的模拟复制和 10 的秘密复制在共享剪贴板保护完成前不能作为正式交付能力。

## 01 增强截图与贴图

**M1：截图—编辑—保存/复制—贴图闭环（Cursor 首批任务）**

- 真实冻结帧先于遮罩创建；正确处理显示器物理像素、逻辑坐标、缩放和负坐标。
- 手动拖选、八手柄调整、方向键 1px 平移、Shift 微调宽高、Space 拖移；接入已有智能区域算法，可用能力如实报告。
- 矩形、箭头、马赛克、序号、文字等标注，撤销/重做，放大镜和 RGB/HEX 取色。
- 原始图像走二进制响应或受控资源协议，避免大帧 JSON/base64 来回复制；不能把跨 IPC 传输误称为绝对零拷贝。
- 保存不覆盖源文件；复制为真实图片；`pin-img-{id}` 可拖动、缩放 10%–500%、调透明度、双击折叠、关闭释放。
- `capture-overlay` 与工具栏层级可交互，Esc 取消销毁；模块关闭销毁所有自有窗口并取消任务。

**M2：系统 OCR 与完整智能选区**

- macOS Vision、Windows 原生 OCR，真实文本及坐标；无权限/缺语言包不伪造结果。
- 原生窗口/无障碍控件/视觉候选三级区域与滚轮/Tab 父子层级切换。
- 自定义 ONNX 模型、执行提供器能力探测和回退、180 秒闲置释放按完整说明书单独验收；不得因 M1 可用而删除此项。

**M3：长截图与 GIF**

- NCC 拼接，重复帧、固定头尾、无位移/低置信度、取消、长度和内存上限。
- 区域、分辨率、帧率设置，真实 GIF 编码，可解码产物、取消清理和停用等待。

**关键验收**：Retina 裁剪尺寸正确；画布操作后工具栏仍可点击；退出及关闭开关无残留；真实 OCR 样本、滚动样本与 GIF 解码分别有证据。

## 05 应用使用时长统计

**M1：真实采样与计时**

- 独立 `mod-app-usage`，稳定 Bundle ID/应用标识，不能继续把进程名拼接当成唯一应用 ID。
- 原生前台应用、输入空闲、锁屏和息屏；单调时钟计算时长，跨小时/跨日正确切段。
- 焦点切换/每 60 秒增量落盘，退出/停用刷写一次；重启不把离线时间计入，不重复统计。
- 音频播放对 AFK 的例外属于完整需求：需真实音频活动能力。尚不可获取时显示限制，不能假装“无音频”。

**M2：报表与设置**

- 每日总览、小时分布、分类占比、应用分类与忽略名单；空数据和日期范围边界。
- 不采集按键内容；窗口标题按设置控制保留。关闭模块后停止采样，保留历史；重启保持开关。

**关键验收**：注入时间源测试切换、睡眠跳变、时区/夏令时边界；实机按已知时间切换应用/锁屏，核对数据库和图表，不用假时长充当实机证据。

## 07 全局划词翻译

**M1：可控触发的真实选区与翻译**

- `mod-translator` 注入 `SelectionExtractor`；先 AX/UIAutomation，再按设置启用模拟复制。模拟复制须等待共享剪贴板租约契约，不自行依赖模块 02 的具体类型。
- 默认先支持快捷键/显式按钮，保留目标应用焦点，不能先让气泡抢焦点再读取选区。
- Google 官方 API、DeepL、OpenAI 兼容源的配置/请求/取消/超时；需要凭据的源未配置时明确提示，不使用非官方接口伪装免费默认服务。
- SSE 分片、UTF-8 跨块、错误返回、取消旧请求及迟到结果隔离；网络操作不阻塞 UI。
- API Key 存系统凭据库或经已审查方案加密保存；历史记录可关闭，选区不自动外发。

**M2：鼠标划词与完整服务源**

- 拖拽结束事件、悬浮图标、屏幕边缘气泡布局、窗口失焦销毁；全局钩子可停用且资源释放。
- 百度/腾讯/有道等按官方 API 分批扩展；缺凭据的真实调用明确未验收。
- 模拟复制兼容文本/图片/多格式及剪贴板变更竞态；若不能完整恢复，明确禁用该降级链，不能静默丢内容。

**关键验收**：多应用取词、权限拒绝、剪贴板不污染历史且原内容恢复；旧响应不覆盖新结果；停用中止监听、请求、浮窗；真实 API 验证只用无敏感的专门文本。

## 10 生物识别加密密码本

**M0：先审查密钥与数据格式**

- 明确主密码 KEK、随机 DEK、Argon2id 参数、AES-256-GCM 每次加密独立 nonce、字段/记录 AAD、格式版本与迁移方案。
- 说明书示例只有一个 `entry_nonce`，不能照抄后让多个字段共用 key/nonce；改为每字段加密信封，或一次加密完整记录并绑定记录 ID/版本。
- Touch ID/Hello 的“认证成功”不等于 DEK 已受生物识别保护；必须设计 Keychain/DPAPI 等密钥包装与实际访问控制。不能有可绕过认证的直接取钥路径。
- 取消、设备认证不可用、损坏数据、主密码错误和恢复路径必须有明确行为。先交设计，再编写核心逻辑。

**M1：主密码闭环**

- 初始化、锁/解锁、字段密文持久化、CRUD/搜索/密码生成，锁定态拒绝所有敏感 IPC。
- `Zeroizing` 管理后端密钥；前端揭示值按需短驻留，锁定/离开页面/关闭/停用时擦除状态。
- 180 秒空闲锁定及休眠/锁屏/关闭窗口立即锁定。不得使用“每次后台轮询都刷新空闲时间”的实现。
- 30 秒延迟清理只在剪贴板仍由本次复制拥有时执行，不能清掉用户后续复制内容；共享屏蔽租约覆盖实际暴露期。

**M2：生物识别与完整防泄漏**

- 真正的原生认证及安全钥匙封装/解封，UI 不阻塞；拒绝和取消不得解锁。
- 解密篡改拒绝、nonce 唯一性、锁定竞态、重启密文完整性、剪贴板与历史联动；只用虚构测试凭据。
- 通过独立审查及真机验证后才标为可用；不自动导入现有浏览器/系统密码。

## 并行规则与交付门槛

- 每个成员从包含 `f0db53d` 的统一基线创建独立 worktree/分支；不切换主工作区，不修改其他成员目录，不 merge/push 主分支，不改全局代理或安全设置。
- 自己负责 `crates/mod-*`、对应前端组件、独立平台适配文件和测试。公共装配、Cargo 清单/锁、字典、Host 事件与 IPC 路由改动集中列入交接；只做自己所需增量，不覆盖其他功能。
- 配置/测试/业务代码分离；中文注释；真实能力，允许显式测试适配器但生产禁止 Mock 回退。同步等待/加解密/网络等重任务不能阻塞 AppKit 事件循环。
- 以小提交交付，每个提交正文记录实际使用的智能体和模型，不虚构署名；模型发生变化如实记录。
- 每批提交 `HANDOFF`：提交号、接口/配置/迁移、公共文件清单、实测命令结果、GUI 用例和未执行项。
- Codex 按“05 → 01 M1 → 07 → 10”逐项集成；01 后续阶段可独立迭代。密码本需额外密钥设计审查；不能仅凭测试全绿投入真实秘密。
- 每个阶段检查开关、禁用 IPC、配置持久化、升级保留数据、任务取消、窗口层级、权限拒绝。严格前端构建、模块及工作区测试通过后打 App，用隔离数据做实际 GUI；物理快捷键、Windows、多显示器未测须单列。
- 不承诺固定完工时点；按设计、首个可用闭环、完整功能、集成验收四种状态报告进度，避免把“已写代码”当成“已交付”。
